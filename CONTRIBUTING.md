# Contributing

Thanks for wanting to help. A few simple rules:

1. Open an issue first for anything bigger than a small fix, so we agree before you spend time.
2. Keep pull requests small and focused. Match the style of the surrounding code.
3. Run `pnpm typecheck` before you push.
4. Every pull request needs to agree to the [Contributor License Agreement](CLA.md). Add this line to the pull request description:

   `I have read and agree to the momo Contributor License Agreement.`

Security problems: please don't open a public issue. Email me instead (address on my GitHub profile).
